## 1. 四柱排盘

来源：`lunar-typescript`

入口：

```ts
Solar.fromYmdHms(year, month, day, hour, minute, 0)
solar.getLunar().getEightChar()
```

展示字段：

- 年柱
- 月柱
- 日柱
- 时柱

规则性质：干支历、节气体系下的固定排盘结果。

准确性：只要输入时间、真太阳时设置和库计算无误，结果为固定答案。

## 2. 真太阳时

系统支持两种模式：

- 北京时间：直接按用户输入时间排盘。
- 真太阳时：根据出生地近似经度修正时间后排盘。

当前真太阳时修正方式：

```ts
offsetMinutes = Math.round((longitude - 120) * 4)
```

说明：

- 中国标准时间以东经 120 度为基准。
- 经度每差 1 度，约差 4 分钟。
- 当前地点经度为近似值，来自省市县选择后的系统估算。
